## 🚀 Overview

**Philips SmartHome Controller** is a Python application that enables remote control and monitoring of Philips TVs through the local network.

The project focuses on practical experience with:

- 🌐 Network communication
- 🔑 API authentication
- 🏠 Smart Home integration
- 🔒 Secure credential management
- 🐍 Clean Python development

The goal was to build a real-world automation solution that interacts with an IoT device without requiring the original remote control.

---

# ✨ Features

| Feature | Description |
|---|---|
| 📡 TV Connection | Connects to Philips TVs over the local network |
| 🔍 Status Monitoring | Checks the current power state |
| 🔌 Power Control | Turns the TV on and off remotely |
| 🔄 Toggle Mode | Switches between power states |
| 🔐 Secure Config | Uses environment variables for sensitive data |
| ⚡ Lightweight | Simple and efficient Python implementation |
